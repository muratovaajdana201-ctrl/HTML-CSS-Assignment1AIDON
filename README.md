## About the Project

This project is a simple personal webpage created using HTML and CSS.
The webpage contains information about me, my hobbies, favorite websites, university subjects, and a contact form.

## Tasks Completed

### Part 1 - HTML Basics

* Created the basic HTML structure.
* Added headings from h1 to h3.
* Added paragraphs and text formatting.
* Created ordered and unordered lists.
* Added a personal photo.
* Added several links.
* Added a "Click Me" button.

### Part 2 - Tables and Forms

* Created a table with subjects, days and time.
* Added emojis to the webpage.
* Created a contact form.
* Added Name, Email and Favorite Color inputs.
* Added a Submit button.

### Part 3 - CSS

* Used inline CSS.
* Used internal CSS.
* Created an external `style.css` file.
* Used element, class and ID selectors.
* Added colors, fonts, margins, padding and borders.
* Used different units: px, %, em and rem.

### Part 4 - Additional CSS Features

* Added a favicon.
* Used header, main and footer elements.
* Used `position: static`, `relative` and `absolute`.
* Used `float` and `clear`.
* Applied the CSS box model.
* Prepared the website for publishing with GitHub Pages.
